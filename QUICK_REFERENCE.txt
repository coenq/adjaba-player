## 📱 Manual Commands

| Command | What It Does |
|---------|-------------|
| `setup_emulator.bat` | Create Android Virtual Device |
| `run_emulator.bat` | Start the emulator |
| `gradlew clean build` | Build the app |
| `gradlew installDebug` | Install app on emulator |
| `adb devices` | List connected devices |
| `adb shell am start -n com.adjaba.adplayer/.activities.SelectScreens` | Launch app |
| `adb logcat \| findstr "Adjaba"` | View app logs |
| `adb shell am force-stop com.adjaba.adplayer` | Force stop app |
| `adb emu kill` | Stop emulator |

## 🔴 Emergency Fixes

### App won't start
```batch
adb uninstall com.adjaba.adplayer
gradlew installDebug
```

### Still won't work?
```batch
adb logcat | findstr "Error"
REM → Check output for crash details
```

### Emulator too slow?
```batch
REM Windows: Use compatibility mode
REM Disable GPU: Edit run_emulator.bat (remove -gpu)
REM Reduce RAM: Change hw.ramSize=1024
```

### Device not found?
```batch
adb kill-server
adb start-server
adb devices
```
