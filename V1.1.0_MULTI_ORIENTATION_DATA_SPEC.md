## 🏗️ Architecture: How It Works Across Orientations

### **Current Architecture (v1.0.3)**
```
SelectScreens.java
   ↓ (User selects orientation)
   ├──> Landscape → AdvertWatching.java (ConstraintLayout)
   ├──> Portrait → AdvertWatching.java (ConstraintLayout)
   └──> Forced Portrait → AdvertLandWatch.java (rotated layout)
```

### **New Architecture (v1.1.0)**
```
SelectScreens.java
   ↓ (User selects orientation + layout type)
   ├──> Landscape
   │      ├──> Single Zone → AdvertWatching.java (current behavior)
   │      └──> Multi-Zone → AdvertWatching.java + ZoneContainerView
   │
   ├──> Portrait  
   │      ├──> Single Zone → AdvertWatching.java (current behavior)
   │      └──> Multi-Zone → AdvertWatching.java + ZoneContainerView
   │
   └──> Forced Portrait (TV rotated)
          ├──> Single Zone → AdvertLandWatch.java (current behavior)
          └──> Multi-Zone → AdvertLandWatch.java + ZoneContainerView
```

**Key Insight:** Zone layouts adapt to screen dimensions automatically!

```java
public class AdvertWatching extends AppCompatActivity {
    // ...existing fields...
    
    // v1.1.0: Multi-zone support
    private FrameLayout zoneContainer;
    private ZoneLayout currentLayout;
    private Map<Integer, View> zoneViews = new HashMap<>();
    
    // v1.1.0: Content handlers
    private SecureSignageWebView webContentView;
    private LiveStreamManager liveStreamManager;
    private SocialMediaManager socialMediaManager;
    
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.fragment_advert_watching);
        
        // Initialize v1.1.0 components
        zoneContainer = findViewById(R.id.zoneContainer);
        webContentView = findViewById(R.id.webContentView);
        
        // Check if multi-zone enabled
        if (DataHolder.getInstance().multiZoneEnabled) {
            initializeMultiZoneLayout();
        }
        
        // Initialize content managers
        liveStreamManager = new LiveStreamManager(this, adPlayerView);
        socialMediaManager = new SocialMediaManager(this);
        
        // ...existing onCreate code...
    }
    
    private void initializeMultiZoneLayout() {
        currentLayout = new ZoneLayout(DataHolder.getInstance().layoutType);
        currentLayout.setActive(true);
        
        // Create zone views dynamically
        for (ZoneLayout.Zone zone : currentLayout.getZones()) {
            View zoneView = createZoneView(zone);
            zoneViews.put(zone.zoneId, zoneView);
            zoneContainer.addView(zoneView);
        }
        
        zoneContainer.setVisibility(View.VISIBLE);
        Log.i("AdvertWatching", "✅ Multi-zone layout initialized: " + 
              currentLayout.getLayoutType());
    }
    
    private View createZoneView(ZoneLayout.Zone zone) {
        // Create appropriate view based on zone content type
        FrameLayout zoneFrame = new FrameLayout(this);
        
        // Set zone dimensions (convert % to pixels)
        DisplayMetrics dm = getResources().getDisplayMetrics();
        int width = (int) (dm.widthPixels * zone.widthPercent / 100f);
        int height = (int) (dm.heightPixels * zone.heightPercent / 100f);
        int x = (int) (dm.widthPixels * zone.xPercent / 100f);
        int y = (int) (dm.heightPixels * zone.yPercent / 100f);
        
        FrameLayout.LayoutParams params = new FrameLayout.LayoutParams(width, height);
        params.leftMargin = x;
        params.topMargin = y;
        zoneFrame.setLayoutParams(params);
        zoneFrame.setTag("zone_" + zone.zoneId);
        
        return zoneFrame;
    }
}
```

## 🎨 Orientation-Specific Layout Rendering

### **How Zones Adapt to Orientation**

#### **Landscape (1920x1080):**
```
┌──────────────────────────────────┐
│     Main Video (70%)            │
│     Zone 1: 1920x756px          │
├──────────────────────────────────┤
│  Bottom Bar (30%)               │
│  Zone 2: 1920x324px             │
└──────────────────────────────────┘
```

#### **Portrait (1080x1920):**
```
┌──────────────┐
│ Main Video   │
│ (70%)        │
│ Zone 1:      │
│ 1080x1344px  │
├──────────────┤
│ Bottom Bar   │
│ (30%)        │
│ Zone 2:      │
│ 1080x576px   │
└──────────────┘
```

#### **Forced Portrait (TV Rotated - 1080x1920 logical):**
```
Same as Portrait above!
Physical TV is rotated, but Android sees it as portrait dimensions.
Zones render identically to Portrait mode.
```

**Key Point:** Zones use **percentage-based positioning**, so they adapt automatically to ANY screen aspect ratio!
